            人设怎么写
            先写你希望彼此是什么关系，平时怎么称呼。想到开心或甜蜜的时刻，可以写你喜欢怎样分享好消息、表达在意。闹别扭或意见不同时，你希望先听彼此说完，还是把感受直说出来？也可以加一句你在意的边界。
            
        
            
        
            
          
            相处记忆
            
          
            主人在 QQ 私聊发一次「开启记忆」，之后照常聊。小宇会从聊天里挑出你们的暗号、习惯、约好的计划和偏好，留下简短的记忆，聊到相关话题时再想起来。普通对话只保留最近一段。
            
          
            比如你顺口说「以后我们就把加班叫打怪吧」，之后再聊「今天又去打怪了」，小宇就能接上这个梗。
            
          
            
            
            开启记忆
            开始积累聊天里的小事和相处习惯。

            忘记 小事1

            查看记忆
            看学到的相处方式和你单独交代的笔记。
            
            
            清空记忆
            清除记忆和近期对话，保留开关状态。

             新手说明
            第一次用宇伴
            App 用来设置。日常聊天、查资料、听语音，都在 QQ 里。
            
      
            先准备这三样
            1. 宇伴云端网址。还没有的话，先部署一次，把部署后的 HTTPS 网址和管理口令拿到手。查看部署说明。
            2. 任意一家 AI 的 API 密钥。有哪家的就选哪家；不需要为其他模型注册账号。宇伴会用它测试一条很短的回复。
            3. 一个 QQ 机器人。到 QQ 开放平台创建，找到 AppID 和 ClientSecret，回宇伴按提示验证、复制回调地址。
            回到三步向导
            
      
            第一次私聊，先认领主人
            1. 在「开始使用 → 连接 QQ → 认领主人」填一个可选称呼，点击「生成认领码」。
            2. 复制整条认领消息，用你自己的 QQ 在机器人私聊里发送。认领码 10 分钟内有效，只能用一次。
            3. 看到认领成功的回复，就可以开始聊天。之后可在 QQ 私聊发「叫我 小韩」修改称呼。
            宇伴会绑定发出有效认领码的 QQ 账号。别人先发消息，或说「我是你主人」，都不会改变身份。
            
      
            认领后，直接在 QQ 发消息
            分几条讲同一件事就好。宇伴会看上下文和停顿，等你说得差不多再一起回；有时也会连发两三条短消息。
            「今天有点累，想说说话」
            开始陪伴聊天。
            「帮我查一下极光怎么形成」
            查资料并返回来源。
            「用语音回复：给我讲个故事」
            配置语音服务后可用。
            「开启记忆」或「开启问候」
            分别打开相处记忆和主动问候，随时能关。
            
      
            碰到问题时
            只想试试，需要部署吗？
            可以离线写人设和查看安装清单。QQ 收发和主动问候需要部署。
            为什么已经填了机器人，QQ 还是没回复？
            先检查向导里的回调状态，再确认 QQ 平台订阅了单聊消息。发一条测试后，到运行记录看收发结果。
            我在用 GPT，原来的 DSH 插件怎么用？
            在「人设与记忆」导入 AGENT.md、SOUL.md 或挑选记忆摘要，GPT 模型就能使用这些内容。添加便携插件后，按提示选择内容并确认保存。
