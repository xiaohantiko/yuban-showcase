# 宇伴

宇伴把自选 AI 模型接到 QQ 机器人，支持私聊回复和主动问候。网页和桌面管理台用于连接机器人、配置人设和记忆、查看运行记录和模型用量。日常聊天在 QQ 里进行。

[下载最新公开版](https://github.com/xiaohantiko/yuban-showcase/releases/latest) · [查看更新日志](CHANGELOG.md)

## 下载安装

- **macOS 13 或更新版本，Apple 芯片和 Intel**。打开 `Yuban-macOS-universal.dmg`，将「宇伴」拖进「应用程序」，再从「应用程序」打开。更新时先按 `⌘Q` 退出公开版，把新版拖到旧版所在的文件夹，选择「替换」。使用其他发行渠道的宇伴时，请从原渠道更新，以保留连接配置。下载包的签名和公证状态见 Releases 中对应版本的说明。
- **Windows 11 x64**。完整解压 `Yuban-Windows-x64.zip`，再在解压后的目录运行 `Yuban.exe`。桌面界面需要 Microsoft Edge WebView2 Runtime。

桌面端首次打开时，在「云端连接」填入自托管宇伴服务的 **HTTPS 根地址**，保存后注册或登录。地址应直接打开管理台，保留域名和必要的端口即可。若只有本机 HTTP 服务，请用浏览器访问。每个公开发行版附有 `SHA256SUMS.txt`。

## 本地运行

需要 Node.js 22 或更新版本。在仓库根目录运行以下命令。

```sh
npm ci
npm start
```

用浏览器打开 <http://127.0.0.1:4173>。默认监听本机地址。可以先查看管理台和调整演示设置，再配置实际模型和机器人。运行 `npm test` 可检查核心逻辑。

## 自托管并连接桌面端

这一节适合需要让桌面端登录或接收 QQ 回调的部署。将宇伴运行在你自己的服务器上，用自己的域名和有效的 HTTPS 证书提供访问。

1. 在服务进程的环境中设置 `YUBAN_CONSOLE_ACCOUNTS=multi`，并为 `YUBAN_ADMIN_TOKEN` 生成独立的随机值，例如用 `openssl rand -hex 32`。也可把设置保存到服务器上仅自己可读的 `.env`。保管好这个值，避免写进版本库或分享给用户。
2. 用 `npm ci` 安装依赖，再由服务管理器保持 `npm start` 运行。把 HTTPS 反向代理指向服务的本机端口 `4173`，保留原始 Host，由代理将 `X-Forwarded-Proto` 设置为 `https`。服务仍监听本机地址，外部请求经代理进入。
3. 用浏览器打开管理台并注册，妥善保存界面给出的恢复码。若需要初次认领管理员，在注册页的初始化入口使用该部署生成的管理口令。普通成员使用自己的账号。桌面端使用同一 HTTPS 地址及管理台账号。
4. 保留服务的持久化数据目录。默认本地数据在 `.data/`，其中包括运行状态与账号数据。备份和迁移时同时保护数据和部署配置。

## 接入模型和 QQ

1. 在管理台「开始使用 → 选一个 AI」选择服务商和模型，填写自己的 API 密钥，验证后保存。首次接入优先提供 DeepSeek Flash，选择器会还原已有模型配置。GPT 可选 GPT-5.4 mini 或 GPT-6.2 Sol，百炼北京可选千问 Plus 或 Qwen4-Max。模型选择器和用量看板提供前往对应服务商 API 平台的入口。
2. 在管理台「连接 QQ」先选择需要的能力，勾选确认并启用机器人，再填写 QQ 开放平台颁发的 AppID 和 ClientSecret，由管理台验证并保存。首次勾选只是草案，确认前不会启用。 [QQ 开放平台](https://q.qq.com/)
3. 从「连接 QQ」复制管理台显示的回调地址，填入 QQ 开放平台，并订阅单聊消息 `C2C_MESSAGE_CREATE`。部署环境提供的回调路径可能因账号而异，以管理台显示的值为准。
4. 在「认领主人」里生成一次性认领消息，用自己的 QQ 在机器人私聊发送整条消息。认领成功后即可继续在 QQ 聊天。
5. 在「人设与记忆」填写角色，在「主动问候」设置联系节奏、时区和免打扰时段。主人也可以在 QQ 私聊发送「开启问候」或「关闭问候」。

**陪伴插件**里可以分别授权「当地天气」和「主动找我」。问几度、出门要不要带伞，伙伴会参考当地预报，用聊天的口吻回答。选择「智能联系」后，聊到一半安静下来，她可能接着刚才的话题来找你；已经道别或你说在忙时，她会等你。也可以选择固定间隔。

在「主动问候 → 聊天回复方式」选择默认文字、偶尔发语音、文字语音穿插或优先发语音。「偶尔发语音」适合聊开后的晚安和好消息；「文字语音穿插」会在适合朗读的日常闲聊中交替回复。使用官方 DeepSeek 聊天接口时，可另行授权现有密钥合成海星语音，按字符单独计费。取消勾选并保存即可撤销。

打开「主动问候 → 用文字设计声音（百炼）」试听新声音。在「用于 QQ 语音回复」确认音色 ID，填写同一北京业务空间的密钥，点击「授权并用于 QQ」。以前保存的音色 ID 也可以直接填入。换声后沿用已有回复方式，日常合成由百炼计费。点击「停用定制音色」可撤销授权。DeepSeek 和百炼密钥旁都可直接打开对应的充值页。

自托管时，部署者可设置 `YUBAN_MET_WEATHER_ENABLED=1` 开放天气能力。每个账号分享的位置可用 24 小时，换城市可重新定位，也可随时关闭。预报来自 MET Norway，依据 CC BY 4.0 提取并转述。[气象数据来源](https://api.met.no/weatherapi/locationforecast/2.0/documentation) · [许可](https://creativecommons.org/licenses/by/4.0/)

「问候设置」里的对话时区默认使用北京时间，也可选择当前设备时区；已保存的其他时区会继续保留。夜间措辞和免打扰按各账号时区判断。你主动发消息时照常回复；不想被提醒时，可以在 QQ 说「今晚别催」。

使用 DeepSeek 官方模型时，管理台可以检查模型 API 账户的人民币余额。低于默认 5 元时，可向当前授权的 QQ 私聊发送参考自定义昵称与人设的余额提醒。同一段持续低余额状态在确认发送后只提醒一次，余额恢复后可再次提醒。可查询范围和当前检查状态以管理台显示为准。 [DeepSeek 余额接口](https://api-docs.deepseek.com/zh-cn/api/get-user-balance/)

公开版显示四项能力的状态。`dsh-agent-md`、`dsh-remember` 和 `dsh-plugin-memory` 提供人设或所选记忆的便携导入；记忆需先在本人绑定的 QQ 单聊开启，预览确认后再保存。这些适配不会在服务器安装上游插件。第四项 `dsh-chain` 需要原生 DSH 网关；本公开框架会说明缺少该能力，并禁止选择。自定义 GPT Actions 同样需额外接入。

关闭能力后立即停用，再开启或新增能力需明确确认「软重置」。软重置保留账号、QQ 配置、人设、记忆和聊天记录，不会把旧内容重新当成导入同意。三个便携适配也可从「高级接入」管理。

日常经历可以直接分几条发送，系统会短暂等候后续消息。想明确等讲完再回复时，也可以先说「先听我说完」，讲完后再发「我讲完了」。个人 QQ 文本回复可按自然段分成最多三条气泡，语音、资料查询和代码列表保持合并。

## 从源码构建桌面端

- macOS 安装 Xcode 命令行工具后，在仓库根目录运行 `bash desktop/build.sh --dmg`。ZIP 压缩包和磁盘映像输出到 `dist/`。
- Windows 安装 .NET 10 SDK 后，运行 `dotnet publish windows/Yuban.Windows.csproj -c Release -r win-x64 --self-contained true`。将发布目录完整打包，运行时保留其中所有文件。
